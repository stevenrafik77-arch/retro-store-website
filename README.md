# Retro Store - Vintage Shop 📺📻

**Retro Store** هو موقع تجارة إلكترونية تجريبي مصمم بطابع كلاسيكي (Retro) من فترة الثمانينات والتسعينات. يركز المشروع على تقديم تجربة مستخدم فريدة باستخدام تقنيات الويب الحديثة مع لمسة جمالية قديمة.

## ✨ المميزات (Features)

*   **تصميم كلاسيكي (Retro UI):** واجهة مستخدم مستوحاة من الأجهزة القديمة مع تأثيرات CRT Scanlines وتوهج النيون.
*   **نظام تسوق متكامل:** إمكانية إضافة وحذف المنتجات من سلة التسوق وحساب المجموع تلقائياً.
*   **بحث وتصنيف ذكي:** فلترة المنتجات حسب الفئات (راديو، كاميرات، تلفاز، هواتف) أو البحث بالاسم.
*   **ساعة نكسي (Nixie Clock):** عد تنازلي للعروض بتصميم أنابيب النكسي الكلاسيكية.
*   **تفاعلات صوتية:** أصوات "نقرات" كلاسيكية عند التفاعل مع الأزرار.
*   **متجاوب (Responsive):** يدعم العرض على مختلف أحجام الشاشات مع مراعاة معايير الوصول (Accessibility).

## 🛠 التقنيات المستخدمة (Tech Stack)

*   **HTML5:** استخدام العناصر الدلالية (Semantic HTML).
*   **CSS3:** تقنيات Flexbox و Grid، مع رسوم متحركة (Animations) وتأثيرات بصرية متقدمة.
*   **JavaScript (Vanilla):** إدارة منطق المتجر، السلة، والبحث بدون مكتبات خارجية.
*   **Google Fonts:** استخدام خطوط "Press Start 2P" و "Roboto".

## 🚀 كيفية التشغيل (How to Run)

1. قم بتحميل المستودع (Repository).
2. افتح ملف `index.html` في أي متصفح حديث.
3. لا يتطلب المشروع أي خادم (Server) خاص، فهو يعمل كصفحة استاتيكية بالكامل.
